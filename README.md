# ETALIX Ders Programı

Dershane için öğretmen ders programı oluşturucu. Satış amaçlı değildir.

- Öğretmen, grup ve ders bilgileri girilir, **Programı oluştur** ile çakışmasız program çıkar.
- Öncelik: vardiya içinde boş saat (pencere) olmaması, derslerin vardiya başına toplanması.
- Saatler, günler ve hangi grup türünün hangi saatte ders alacağı **Ayarlar**'dan değiştirilir.
- Elle taşınan dersler 📌 sabitlenir, yeniden oluştururken korunur.
- Veriler tarayıcıda saklanır; **Yedek indir / yükle** ile taşınır.

Statik site: `index.html`, `app.js`, `data.js`, `solver.js` (Web Worker), `style.css`. Derleme gerekmez.
